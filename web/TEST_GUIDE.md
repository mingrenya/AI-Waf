# 增强规则管理功能测试指南

## 功能概览

本次开发完成了以下增强规则管理功能：

### 1. OWASP Top 10 规则模板
- ✅ 9 个预定义安全模板（SQL 注入、XSS、命令注入、敏感文件访问等）
- ✅ 按分类和严重性筛选
- ✅ 模板预览和自定义规则名称
- ✅ 一键从模板创建规则

### 2. 规则有效性评分系统
- ✅ 点击即可查看规则评分（0-100 分）
- ✅ 显示真阳性率、假阳性率、拦截率
- ✅ 性能影响指示器（低/中/高）
- ✅ 智能优化建议
- ✅ 评分时间戳

### 3. 一键保护配置文件
- ✅ 三种保护级别：基础/标准/严格
- ✅ 视觉化配置文件卡片
- ✅ 显示包含的分类和规则数量
- ✅ 批量创建规则（自动跳过已存在规则）

## API 端点

### 后端 API
```
GET  /api/v1/rules/templates            - 获取模板列表
POST /api/v1/rules/templates/create-rule - 从模板创建规则
POST /api/v1/rules/effectiveness/calculate - 计算规则评分
GET  /api/v1/rules/profiles              - 获取保护配置文件
POST /api/v1/rules/profiles/apply        - 应用保护配置
```

## 故障排除

### 问题 1: 模板加载失败
**检查：**
- 后端服务是否运行
- MongoDB 连接是否正常
- 初始化脚本是否执行（server/router/router.go 中的初始化代码）

### 问题 2: 评分计算失败
**检查：**
- 规则是否有匹配数据（可能需要先生成一些流量）
- 评分参数是否正确（rule_id, period）
- 日志中是否有错误信息

### 问题 3: 配置文件应用失败
**检查：**
- 数据库中是否已存在同名规则
- 用户是否有创建规则的权限
- 模板 ID 是否有效

## 性能优化

1. **按需加载评分**：评分只在用户点击时计算，避免大量不必要的 API 调用
2. **缓存机制**：评分结果缓存在组件状态中，避免重复计算
3. **虚拟滚动**：规则列表使用无限滚动，仅加载可见数据
4. **批量操作**：保护配置一次性创建多个规则，减少 API 调用
